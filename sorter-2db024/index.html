  1. Copy your Figma file link

    1 minNothing to install

    Open the Figma file that holds your email templates and copy its link from the browser bar (or Share → Copy link). You can paste several links, one per line.

  2. Make a Figma access token

    2 minNothing to install

    In Figma: click your name (top left) → Settings → Security → Personal access tokens → Generate new token. Name it "Auto-Sorter", set File content to Read-only, leave the rest off, and create it. Copy it right away: Figma only shows it once. It stays in your browser and is only sent to Figma.

  3. Open the Auto-Sorter and click "Sort my library"

    1 minRuns in your browser

    Paste the link and the token, then click Sort my library. Big files take a while the first time; after that the library opens instantly in the same browser. Group by brand, type, category or section with the dock at the bottom.

    Open the Auto-Sorter with Pro on →

    Your add-on includes Auto-Sorter Pro: every file on one canvas and the parts library. The button above turns Pro on in one click. On another computer or browser, click Pro in the sorter and paste your key: HOT-SORT-ZA56-CGU9

Using the Atomic Emails method? Put your atoms, molecules and organisms on a Figma page called Parts, in sections named Atoms, Molecules and Organisms, then switch the sorter to Parts. No Parts page yet? Click Atomize emails in Parts mode and the sorter breaks every email into parts for you. Full guide: the help center.
