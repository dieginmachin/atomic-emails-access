# Atomic Emails access pages

Private delivery pages for the Atomic Emails funnel. Each product has one page, at a hard-to-guess path:

| Product | Path |
|---|---|
| $17 Atomic Emails + AI Install Pack | `/kit-466ca3/` |
| $12 1,000 templates | `/templates-20e07f/` |
| $5 Auto-Sorter | `/sorter-2db024/` |
| $97 AI Studio Skill Stack | `/skills-da5faa/` |

To change a link, edit that folder's `index.html` (look for the yellow `mark.ph` placeholders), commit and push. GitHub Pages updates in about a minute. Shared styles are in `style.css`; `progress.js` remembers ticked steps in the buyer's browser.
